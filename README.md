# 灵犀输入法（Lingxi IME）

**完全离线的旗舰级 Android 智能输入法：零网络权限 · 233 万搜狗级大词库 · 内置端侧专属 AI 大模型 · 4 万字大画布手写 · 1Password 内联填充**

灵犀输入法不申请 `android.permission.INTERNET`，从操作系统权限机制上杜绝任何键盘输入、语音、剪贴板或图片上传的可能，同时在本地词库容量、端侧 AI 上下文选句、全字集手写、智能纠错与个性化体验上对标主流旗舰输入法。

## v2.0 核心特性一览

- **Gboard 同款系统生态联动（100% 离线 IPC，零网络权限）**
  - **1Password / Bitwarden / 系统密码库内联自动填充**：原生支持 Android 11+ `InlineSuggestionsRequest`，聚焦账号、密码、通行密钥或验证码输入框时，键盘顶栏自动渲染 1Password / Bitwarden 填充芯片。
  - **最新截图自动气泡 + 最近照片/截图面板**：截屏后 90 秒内键盘顶栏自动弹出缩略图胶囊，点一下即可通过 `CommitContent API` 直接发入微信、QQ、Telegram、短信等聊天框；工具栏内置 `[🖼 图片/截图]` 筛选面板。
- **233 万搜狗级全领域大词库 + 长词分段锁定不回退**
  - 完整启用雾凇基础/扩展词库 + **腾讯百万词向量词库** + **43 万搜狗细胞领域词库 & 清华 THUOCL 11 大领域 & 古诗文成语名句** + **`41448` 全字集注音**（总计 **233.6 万+** 词条）+ `36,000` 词头中文二元与成语接续联想。
  - **长句分段选字锁定**：长拼音中先选定前半段词（如 `qiushuishizhi` 选定 `秋水`）即刻上屏锁定并进入 AI 上文，后续按 `⌫` 退格**绝不退回未选字前的拼音**。
- **内置端侧专属 AI 智能选句（支持双音节语境同音消歧）**
  - 内置 `Lingxi-285M` 裁剪蒸馏模型，不仅优化长句，还支持**有上文时的双音节同音词实时消歧**（如输入 `秋水` 后再打 `shizhi` 智能首选 `✦ 时至`），`90 ms` 极速响应、后台预热加载、打字零卡顿。
- **中英文双引擎智能纠错**
  - **中文邻键误触与倒序纠错（`PinyinCorrector`）**：实时修复手机盲打邻键误触（`nihso→你好`、`shebme→什么`、`xiansai→现在`）、字母倒序（`zhognguo→中国`、`womne→我们`）与连击多按。
  - **英文二维高斯键距纠错与漏空格切分**：支持连续键距拼写纠错、常见易错词修复（`recieve→receive`、`definately→definitely`）与漏空格双词切分（`thebest→the best`）。
- **超宽加高 4 万字生僻字手写面板**
  - 全宽大画布布局（书写面积扩大约 `+75%`，支持「标准 / 加高 / 半屏大框」一键切换）；`⌫` 退格键采用直觉化**整字删除**（画布角标保留单笔撤销 `↶`）；三层识别覆盖 16,384 神经网络直出 + 8.3 万条部件空间组字（支持 `垚、犇、龘、曌、烎、囧、嫑、砳、䶮、𠮷、𨰻、齾` 等生僻字）+ 常见字优先先验。
- **无损等比缩放与深度个性化中心**
  - **可视化大小调节面板（`⊞ → 键盘大小`）**：自由调节键盘高度（`75%～135%`）、单手宽度内缩（靠左 / 居中 / 靠右）、全面屏底部抬高防误触间距、按键与候选独立字号——**所有图标与圆角严格 `1:1` 等比锚定，压缩拉伸绝不变形**。
  - **8 款旗舰主题皮肤 + 无边框模式**：`灵犀自适应`、`凝脂纯白`、`曜石深黑`、`莫兰迪雾蓝`、`樱花落雪`、`松石薄荷`、`暖阳羊皮纸`、`极夜星辰`，支持切换立体边框或纯平无边框风、常驻数字行、全键位长按符号副标提示、多档精细振动强度、滑动空格移光标与左滑退格快删。

## 从源码构建

环境要求：JDK 17、Android SDK 35、NDK `28.0.13004108`、CMake `3.31.6`。

```bash
# 首次拉取第三方预编译库与词库源码
bash tools/fetch_prebuilt.sh
bash tools/fetch_llama.sh
bash tools/fetch_sherpa.sh
bash tools/fetch_rime_sources.sh
bash tools/build_rime_data.sh

# 运行单元测试并构建内置 AI 旗舰版与精简版 APK
./gradlew testDebugUnitTest assembleRelease
./gradlew assembleRelease -PembedAi=false
```
