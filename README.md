# 灵犀输入法（Lingxi IME）

**完全离线的 Android 智能输入法：零网络权限 · 大词库 · 端侧专属小语言模型智能选句 · 内置连写手写**

灵犀输入法不申请 `android.permission.INTERNET`，从操作系统权限机制上杜绝任何键盘输入上传的可能，同时通过端侧语言模型与全句词格重排追平云端输入法的整句准确度。

---

## 下载安装（Release v1.1.0）

前往 [**Releases 页面**](https://github.com/wlx7/ai-keyboard/releases/latest) 下载：

1. **输入法安装包**：`lingxi-1.1.0-arm64.apk`（内置中英文词库、中文二元联想、简繁转换、离线连写手写与 **内置 `sherpa-onnx` 流式离线语音识别模型**，全部开箱即用）。
2. **（推荐）端侧 AI 智能选句模型**（任选其一拷入手机，在「设置 → AI 智能选句 → 导入模型文件」中选中即可）：
   - **`zh-lm-lingxi-285m-q4_0.gguf`（`154.5 MiB`，主力推荐）**：专为中文输入法裁剪与蒸馏，选句首选正确率 **`85.6%`**（100% 追平 `Qwen3-0.6B-Base`，零负向改错，体积缩小 61%，速度提升 2.1 倍）。
   - **`zh-lm-lingxi-80m-q4_0.gguf`（`46.7 MiB`，超轻量极速版）**：适合旧机型或极致省电场景，单次打分仅约 `58 ms`。
   - 亦完全兼容原版 `zh-lm-qwen3-0.6b-base-q4km.gguf`（`397 MB`）。

> 首次切换到中文键盘时会在后台自动部署雾凇词库（约十余秒，仅首次需要）。

## 核心特性

- **精致键盘与排版细节**
  - iOS / 微信输入法风视觉与按键气泡，长按首排输入数字、长按空格滑动移动光标、长按退格加速连删、支持多指滚动快打与系统深浅色自适应。
  - `[中/英]` 主副角标设计、全键盘自适应字号防溢出、全角中文标点墨迹光学居中。
- **中文全方案支持（`librime` 1.16.1）+ 中文上下文联想 + 模糊拼音**
  - 内置 **雾凇全拼**、**九宫格拼音（专用 3×3 键盘）**、**6 种双拼**（小鹤 / 自然码 / 微软 / 搜狗 / 智能 ABC / 紫光）、**五笔 86（极点，带字根角标）**、**仓颉五代（带字根角标）**。
  - **独立拼音预编辑栏（`PreeditBar`）**：输入时在候选栏上方清晰实时展示音节串，兼容各类浏览器地址栏与自绘输入框。
  - **12 组模糊拼音设置**：支持 `z/zh`、`c/ch`、`s/sh`、`n/l`、`f/h`、`r/l`、`k/g` 与 `an/ang`、`en/eng`、`in/ing`、`ian/iang`、`uan/uang` 自由开关及一键南方模糊音预设，全拼/双拼/九宫格通享。
  - **中文二元与成语接续联想（`AIKBZH01`）**：上屏后毫秒级给出高频口语接续词、四字成语下半句及个人习惯二元词联想，支持连续点选成句。
  - **智能浏览器地址栏 / 搜索框适配**：地址栏同时支持直接输入中文搜索、英文单词候选补全及域名后缀快捷输入。
- **内置离线流式语音输入（`sherpa-onnx` Apache-2.0）**
  - 内置 `streaming-zipformer-small-ctc-zh-int8` 端侧流式语音模型，**无需联网权限、不依赖谷歌或厂商语音服务**，任意国产/海外 ROM 飞行模式下均可边说边实时出字。
- **端侧专属 AI 整句重排（`llama.cpp`）**
  - 隐藏会话执行**全句脊柱漫游 + 多分词边界分支搜索**（不污染用户词库），结合光标前上文计算 `log P(候选整句 | 上文)`。
  - 仅在长拼音（≥ 3 音节）且停顿 150 ms 时触发；继续打字毫秒级中断后台推理，不卡顿、低功耗，并随用户选词习惯自适应调节权重。
- **英文词库与二元上下文联想（`AIKBEN02`）**
  - 23.3 万词频 + 11.6 万条二元语法边：支持**空格后下一词预测**、**结合前词的拼写纠错与补全**（含 `its` / `it's` 语境消歧）、专有名词自动大小写（`Monday`、`iPhone`、`GitHub` 等）、退格一键撤销自动纠错及个人二元词频自学习。
- **内置轻量离线手写（`ochwpro` MIT 模型）**
  - 仅增加 `3.3 MB` 体积（支持 7,356 类汉字/字母/数字，单次推理约 `3.7 ms`），支持单字、**多字连写与叠写 DP 自动切分**及繁体输出。
- **极简顶栏工具箱与安全剪贴板**
  - 空闲态极简工具栏：`⊞` 多功能抽屉（方案快切、简繁、光标编辑栏 `← → 全选 复制 粘贴`）、手写快切、离线优先系统语音输入。
  - **安全剪贴板**：自动屏蔽 Android 13+ 敏感密码剪贴板；未置顶内容纯内存驻留且 **1 小时自动过期销毁**，仅置顶条目本地保留。

## 从源码构建

环境要求：JDK 17、Android SDK 35、NDK `28.0.13004108`、CMake `3.31.6`。

```bash
# 首次拉取第三方预编译库与词库源码
bash tools/fetch_prebuilt.sh
bash tools/fetch_llama.sh
bash tools/fetch_sherpa.sh
bash tools/fetch_rime_sources.sh
bash tools/build_rime_data.sh

# 运行单元测试并构建 Release 安装包
./gradlew testDebugUnitTest assembleRelease
```
