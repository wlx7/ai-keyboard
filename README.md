# 灵犀输入法（Lingxi IME）

**完全离线的旗舰级 Android 智能输入法：零网络权限 · 所见即所得实时调参预览 · 微信键盘辅助输入全对齐 · 233 万搜狗级大词库 · 内置端侧专属 AI 大模型 · 4 万字大画布手写 · 1Password 内联填充**

灵犀输入法不申请 `android.permission.INTERNET`，从操作系统权限机制上杜绝任何键盘输入、语音、验证码、剪贴板或图片上传的可能，同时在本地词库容量、端侧 AI 上下文选句、全字集手写、智能纠错、辅助输入与个性化体验上全面对齐主流旗舰输入法。

## v2.1 核心特性一览

- **所见即所得实时键盘调参预览（告别盲调）**
  - 设置页底部内嵌 **1:1 真实渲染的常驻键盘预览坞**（支持 `[拼音键盘]` / `[手写面板]` / `[九宫格]` 一键切换及折叠，唤起真实系统键盘打字时自动避让）。
  - 拖动任意主题配色、高度、单手宽度、圆角、无边框、按键/候选字号、数字行、符号副标、手写画布高度与笔迹粗细滑块时，底部真实键盘**以 60/120fps 实时刷新**。
- **微信键盘同款 9 大「辅助输入」全对齐（100% 纯本地零联网）**
  - **回车键发送**：多行聊天框右下角切换为蓝色「发送」直发消息，长按回车仍可插入换行。
  - **中文和数字间加空格 / 中文和英文间加空格**：自动插入盘古之白（`你好 2024`、`你好 Hello`），智能保留 `5G`、`iPhone16` 与中文标点边界不拆散。
  - **验证码自动提取**：收到短信通知或复制验证码后，键盘顶栏弹出 `🔑 2046 · 来自「信息」` 胶囊一键填入，纯内存 90 秒自动销毁、绝不落盘。
  - **中英文双击空格输入句号**：中文模式双击空格输出 `。`，英文模式输出 `. `。
  - **输入后联想 + 应景 Emoji 表情联想**：打完词自动推荐后续词与应景表情（如 `生日快乐 → 🎂 天天开心`、`谢谢 → 🙏`）。
  - **首字母自动大写 + 12 组模糊拼音 + 中英双语智能纠错**。
- **Gboard 同款系统生态联动（100% 离线 IPC，零网络权限）**
  - **1Password / Bitwarden / 系统密码库内联自动填充**：原生支持 Android 11+ `InlineSuggestionsRequest`，聚焦账号、密码、通行密钥框时键盘顶栏自动渲染填充芯片。
  - **最新截图自动气泡 + 最近照片/截图面板**：截屏后 90 秒内键盘顶栏自动弹出缩略图胶囊，点一下通过 `CommitContent API` 直发聊天框。
- **233 万搜狗级全领域大词库 + 内置 AI 智能选句 + 4 万字生僻字大画布手写**
  - 雾凇基础/扩展词库 + **腾讯百万词向量** + **43 万搜狗细胞词库 & 清华 11 大领域 & 古诗文名句** + **`41448` 全字集注音**；长拼音分段选字锁定退格不回退。
  - 内置 `Lingxi-285M` 裁剪蒸馏模型，支持双音节语境同音消歧（`秋水 + shizhi → ✦ 时至`）。

## 从源码构建

环境要求：JDK 17、Android SDK 35、NDK `28.0.13004108`、CMake `3.31.6`。

```bash
# 首次拉取第三方预编译库与词库源码
bash tools/fetch_prebuilt.sh
bash tools/fetch_llama.sh
bash tools/fetch_sherpa.sh
bash tools/fetch_rime_sources.sh
bash tools/build_rime_data.sh

# 运行单元测试并构建内置 AI 旗舰版与精简版 APK
./gradlew testDebugUnitTest assembleRelease
./gradlew assembleRelease -PembedAi=false
```
